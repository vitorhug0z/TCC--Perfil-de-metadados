Guia de utilização do Perfil de Metadados para Estudos de Caso.

1. Sobre o Sistema

Este sistema foi desenvolvido como parte de uma proposta para estruturar e organizar metadados de estudos de caso em Engenharia de Software. Seu objetivo é apoiar pesquisadores, estudantes e profissionais na descrição padronizada das informações presentes em estudos de caso, permitindo maior organização, recuperação e reutilização do conhecimento produzido.


Os metadados são informações que descrevem um recurso. No contexto dos estudos de caso, eles permitem registrar aspectos importantes da pesquisa, como o problema investigado, os objetivos, a unidade analisada, as estratégias de coleta de dados e os métodos de análise utilizados. A utilização de um perfil de metadados padronizado contribui para melhorar a qualidade da documentação dos estudos e facilitar comparações entre pesquisas.


A estrutura utilizada nesta aplicação foi construída com base em elementos do padrão Dublin Core e em características específicas da metodologia de estudos de caso, resultando em um perfil voltado para a representação de informações metodológicas e contextuais relevantes para a Engenharia de Software.

2. Como Utilizar o Sistema

  1. Preencha os campos da seção Informações Gerais.
  2. Descreva a Formulação do Problema investigado.
  3. Defina a Unidade-Caso analisada.
  4. Informe o Número de Casos estudados.
  5. Descreva as estratégias de Coleta de Dados.
  6. Informe os procedimentos de Análise e Interpretação dos Dados.
  7. Clique em Ver Respostas para revisar as informações preenchidas.
  8. Gere o arquivo XML contendo os metadados estruturados.

3. Estrutura do Perfil

A tabela abaixo apresenta os elementos do perfil de metadados, seus contextos, generalizações e regras de utilização.

Elemento Contexto Generalização Regra de Uso
dc:title Informações Gerais - Inserir o título completo do estudo de caso.
dc:creator Informações Gerais - Inserir o nome do pesquisador responsável pelo estudo.
dc:date Informações Gerais - Informar a data de realização ou publicação do estudo.
dc:language Informações Gerais - Informar o idioma principal do estudo.
dc:type Informações Gerais - Informar o tipo do recurso.
dc:subject Problem Definition problemDefinition Agrupar os metadados relacionados à formulação do problema.
dc:description Problem Definition problem Descrever o problema investigado pelo estudo.
dc:description Problem Definition objective Informar o objetivo principal da pesquisa.
dc:description Problem Definition studyNature Classificar o estudo como exploratório, descritivo ou explicativo.
dc:subject Unit Case Definition unitCaseDefinition Agrupar os metadados relacionados à definição da unidade-caso.
dc:description Unit Case Definition unitCase Descrever a unidade analisada pelo estudo.
dc:description Unit Case Definition unitName Informar o nome da unidade analisada.
dc:description Unit Case Definition unitType Informar o tipo da unidade analisada (empresa, equipe, projeto, sistema etc.).
dc:coverage Unit Case Definition spatial Informar a delimitação espacial do estudo.
dc:coverage Unit Case Definition temporal Informar a delimitação temporal do estudo.
dc:description Unit Case Definition caseStudyModality Informar a modalidade do estudo de caso (intrínseco, instrumental ou coletivo).
dc:subject Case Number Definition caseNumberDefinition Agrupar os metadados relacionados ao delineamento e quantidade de casos.
dc:description Case Number Definition caseDesign Informar se o estudo é de caso único ou múltiplos casos.
dc:description Case Number Definition caseCount Informar a quantidade de casos analisados.
dc:subject Data Collection dataCollection Agrupar os metadados relacionados à coleta de dados.
dc:description Data Collection evidenceSources Listar as fontes de evidência utilizadas na pesquisa.
dc:description Data Collection dataCollectionTechniques Informar as técnicas empregadas na coleta dos dados.
dc:description Data Collection technique Informar uma técnica específica utilizada na coleta dos dados.
dc:description Data Collection validityStrategy Descrever a estratégia utilizada para validação dos dados coletados.
dc:subject Data Analysis dataAnalysis Agrupar os metadados relacionados à análise e interpretação dos dados.
dc:description Data Analysis analysisNature Informar a natureza da análise realizada.
dc:description Data Analysis theoreticalFramework Informar o referencial teórico utilizado na análise e interpretação dos resultados.

4. Glossário dos Elementos Dublin Core

Elemento Significado
dc:title Título completo do estudo de caso.
dc:creator Autor(es) ou pesquisador(es) responsáveis pelo estudo.
dc:date Data de realização ou publicação do estudo.
dc:language Idioma principal do estudo.
dc:type Tipo do recurso descrito.
dc:subject Elemento utilizado para agrupar informações relacionadas a um contexto específico.
dc:description Elemento utilizado para registrar descrições textuais sobre determinado aspecto do estudo.
dc:coverage Elemento utilizado para representar delimitações espaciais ou temporais do estudo.

5. Glossário dos Contextos

Contexto Significado
Informações Gerais Metadados básicos utilizados para identificar e caracterizar o estudo de caso.
Problem Definition Contexto responsável por registrar o problema investigado, os objetivos e a natureza da pesquisa.
Unit Case Definition Contexto destinado à descrição da unidade analisada pelo estudo de caso.
Case Number Definition Contexto utilizado para registrar o delineamento e a quantidade de casos analisados.
Data Collection Contexto responsável pela documentação das fontes de evidência e técnicas utilizadas na coleta de dados.
Data Analysis Contexto destinado à descrição dos procedimentos de análise e interpretação dos dados coletados.
